## 4. Analyst Findings & Behavioral Assessment

1. **Activity Evaluation:**
   Source IP `198.51.100.45` initiated an automated dictionary attack against `srv-app-01`. Five failed attempts were recorded within 40 seconds.
2. **Access & Compromise Validation:**
   At 07:45:50Z, the attacker successfully authenticated using valid credentials. Active session `sess-9f82d1` was established.
3. **Analyst Notes & Observations:**
   - Source IP has no previous administrative history on this host.
   - Root password was weak or discovered in common password dictionaries.

---

## 5. False Positive Assessment

- **Known Baseline Triggers:** Administrator typing wrong password several times before remembering the correct one.
- **Verification Result:** The velocity of attempts (<10s intervals) and standard wordlist passwords confirm an automated dictionary attack tool. Verified **True Positive**.

---

## 6. Containment, Remediation & Recommended Response

- **Immediate Containment:**
  - Invalidate active session `sess-9f82d1` and terminate process tree.
  - Drop all traffic from `198.51.100.45` at the network perimeter.
- **Eradication & Remediation:**
  - Disable direct SSH root login (`PermitRootLogin no` in `/etc/ssh/sshd_config`).
  - Require SSH key-based authentication with passphrase and MFA.
  - Install and configure Fail2Ban / IP rate limiting.

---

## 7. Final Conclusion & Sign-Off

The brute-force compromise was confirmed by telemetry. Immediate quarantine and credential remediation have been executed.
